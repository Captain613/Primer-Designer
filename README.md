# RPA / LAMP 引物设计助手 v1.0

一个可离线运行的中文 Windows 程序：输入单条序列，输出 **RPA / LAMP 普通扩增与 SNP 选择性扩增候选**。候选需实验筛选验证，排序分数不是扩增成功率或等位基因区分率。

## v1.0 发布说明

v1.0 将最新程序正式定版，整合已完成的 LAMP 宽默认参数，以及同时保留局部优选和拼接 FIP/BIP 结构优选候选的预筛改进；最终评分公式不变。本次仅切换版本标识和发行目录。此前功能改进验证中，用户提供的 CYP2C9 mLAMP 序列恢复原完整首组，分数为 82.59，20 个测试套件全部通过；该结果属于定版前的功能验证。

## LAMP 默认搜索范围

LAMP 参数页分为“长度与 GC”和“各区段 Tm”。F3、B3、F2、B2、F1c、B1c、LF、LB 各有独立上下限及“无限制”，设置实际用于对应区段的候选筛选、SNP 改写后复核及环引物搜索，并记录在导出报告中。F2c 是 F2 的互补区；同一条件的完全匹配双链模型下两者共用 Tm，不重复创建独立筛选项。

Eiken 的 [PrimerExplorer V5 设计手册](https://primerexplorer.jp/e/v5_manual/pdf/PrimerExplorerV5_Manual_1.pdf)推荐 F3/B3/F2/B2 约 59–61°C、F1c/B1c/LF/LB 约 64–66°C、GC 40–65% 及 F2–B2 跨度 120–160 bp。这些窄范围同时作为六区硬条件时，部分位点容易没有候选。[V5 操作手册第 24 页](https://primerexplorer.jp/e/v5_manual/pdf/PrimerExplorerV5_Manual_2.pdf)也建议候选过少时逐步调整长度和 Tm。本程序当前将普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP 的默认允许搜索范围统一设为每区段长度 **17–30 nt**、GC **30–75%**、F3/B3/F2/B2 Tm 各 **52–68°C**、F1c/B1c/LF/LB Tm 各 **58–72°C**、F2–B2 跨度 **100–220 bp**、F3–B3 跨度 **110–350 bp**，最多输出 10 组。默认 Tm 范围中点仍为 60/65°C；排序仍偏好 GC 50%、长度 22 nt、F2–B2 跨度 140 bp 和 F3–B3 跨度 200 bp。手动修改 Tm 范围后，排序目标随有效范围中点变化；任意一端无限制时回退到 60/65°C。程序不会越过用户在界面上明确设定的范围。

此次扩大搜索范围的直接依据是对 mLAMP 补充材料 TP53 引物的核对：B3 长度为 17 nt，F2 按本程序固定参考条件计算的完全匹配 Tm 约为 66.4/67.3°C，超出此前的 18 nt 最短和 65°C 上限。论文未报告这些 Tm 值或 ΔG 阈值；上述新范围是为新位点探索设置的工程搜索边界，适用于各 LAMP 模式，不是论文给出的通用参数。F2–F1 及另一侧对应 5′ 端距离 40–60 nt、外引物与相邻内区间隙 0–60 nt，以及六区段不重叠的要求继续生效。RPA 默认范围保留。调整前后数值及模型见 [LAMP 默认参数与 Tm 模型](docs/LAMP默认参数与Tm模型.md)。

Tm 参考条件改为 Na⁺ 50 mM、Mg²⁺ 4 mM、寡核苷酸 100 nM。根据用户提供的 [PrimerExplorer 附录](https://primerexplorer.jp/e/v3_manual/03.html)，Mg²⁺ 换算为等效单价盐；当前程序保留 SantaLucia 1998 最近邻参数和熵盐校正，与 PrimerExplorer 引用的 1996 参数及 16.6×log[Na⁺] 公式不同。因此不能把本程序的 Tm、候选或评分视为 PrimerExplorer 的复现。参考浓度用于统一计算，不是实验反应配方，也未推算 dNTP 结合后的游离 Mg²⁺。

RPA 的 30–35 nt、GC 30–70%、产物 100–200 bp 原默认已符合 [TwistDx / Abbott 官方设计资料](https://www.globalpointofcare.abbott/us/en/lp/twistdx/support.html)，因此保留。150 bp 偏好与候选评分权重是程序设置，不是厂家给出的最优值。手册另列的 Tm 50–100°C 是借用 PCR 设计软件时的宽范围，不用作 RPA 的硬性 Tm 筛选。RPA 的 F/R Tm 仍按原经验公式作参考，不与 LAMP 的最近邻 Tm 混为同一模型。

网站的末端稳定性 ΔG 与热力学二聚体阈值不能直接套在本程序的连续互补评分上；本次未将这些不同指标替换或冒充为热力学验证。完整来源与计算边界见 `docs` 中的参数依据说明。

## v0.19 BLAST 等待时间优化

在线 BLAST 提交成功并获得 RID 后，程序按 NCBI 返回的预计完成时间（RTOE）安排首次取结果，最少等待 10 秒；RTOE 缺失或格式无效时保守等待 60 秒。此前程序无论预计时间多短，均至少等待 60 秒。首次查询仍遵守全局请求间隔；若任务仍未完成，同一 RID 的后续查询保持至少 60 秒间隔，符合 [NCBI 开发者使用指南](https://blast.ncbi.nlm.nih.gov/doc/blast-help/developerinfo.html)。界面显示当前阶段和已用时间；计时显示不会额外联系 NCBI。

这项调整只减少程序人为增加的首次等待，不能加快 NCBI 实际计算或公共服务器排队。默认仍对所选数据库的全部物种执行短序列敏感检索，一组 LAMP 候选会合并多个结合区段提交；降低返回上限或更换数据库会改变初筛覆盖范围，不能当作等价的提速设置。未经上传确认，程序不会发送序列。
## v0.17 可选 NCBI 在线 BLAST

设计完成后在候选列表选中一组，点击“BLAST 特异性…”或打开“04 BLAST 特异性”页。勾选启用，选择数据库、填写联系邮箱，然后点击“预览并提交 NCBI…”。确认窗口显示实际上传的匿名 FASTA、数据库和邮箱；选择同意后才发送。关闭该功能时，原有引物设计仍在本机运行。

默认数据库为 RefSeq Reference genomes（API 名 `refseq_representative_genomes`），可切换更广泛的 RefSeq 基因组库或 `core_nt`。检索所选库全部物种，不会从 FASTA 标题推断物种。`core_nt` 缺少部分大型真核染色体，不能当作完整基因组筛查。预期登录号仅用于结果本地标注，不限制检索；同一染色体上的其他位点仍可能是脱靶，未命中也不代表特异性通过。

每次仅上传选中候选组的引物或结合区段，不上传完整输入模板、原 FASTA 标题或文件名。RPA 使用真实合成引物序列。LAMP 将 FIP/BIP 拆为 F1c/F2、B1c/B2，两个等位反应分开解释；环引物作为辅助查询。PA-LAMP 使用切后有效 DNA 区段，不把 RNA/C3 或酶切选择性当作普通 DNA BLAST 能够验证的内容。

程序以短序列参数批量检索（word size 7、expect 1000、reward 1、penalty -3、gap 5/2，关闭低复杂度过滤及自动短序列调参）。单条序列至少 7 nt，去重后的总查询长度最多 1,000 nt；超出时会说明原因并停止提交。命中报告显示覆盖率、一致率、坐标/方向、末端 5 nt 错配情况及 E 值。默认以覆盖率≥90%、一致率≥80%作本地候选命中筛选；这些是可调整的工程阈值，不是扩增或 SNP 选择性的实验判据。

组合检查要求命中在同一数据库序列，方向、顺序、不重叠关系和所设跨度相容；普通 RPA 检查引物对，LAMP 检查核心六区。结果是待核查的潜在结合/组合，不模拟 LAMP 全部扩增过程。数据库覆盖、BLAST 局部比对、命中返回上限、组合搜索上限和模板多态性均可能影响结果，不输出“特异性通过”或临床判定。

网络任务可以取消本地等待；取消不能撤回已经发给 NCBI 的序列。请求间隔不少于 10 秒，同一 RID 查询间隔不少于 60 秒，排队期间不会连续催查。失败、超时、解析不全与无命中会明确区分。BLAST 结果可单独导出 TXT、CSV 或 NCBI 原始 XML；原有引物设计报告不自动混入 BLAST 结论。

接口与使用规则：[NCBI Common URL API](https://blast.ncbi.nlm.nih.gov/doc/blast-help/urlapi.html)、[开发者使用指南](https://blast.ncbi.nlm.nih.gov/doc/blast-help/developerinfo.html)、[数据库范围](https://blast.ncbi.nlm.nih.gov/doc/blast-help/blastdatabases.html)。

## 输入界面布局

输入页将筛选参数按“项目 / 下限 / 上限”对齐，每项“无限制”开关与数值同行。输出候选数量、偏好长度和方法选项在右侧单独分组；开始设计和取消按钮固定在页面底部，滚动参数时也能直接操作。标题与序列输入区更紧凑，参数区随 RPA、LAMP、PA-LAMP 自动调整高度。候选数量设置、各模式默认参数与序列颜色规则保持原有行为。

## RPA SNP 的产物长度评分

RPA SNP 模式的“偏好等位(bp)”只评价两种等位反应的产物。对照产物须满足设置的最短/最长范围，但它与偏好长度的距离不影响候选初评、对照优选、候选组分数或对照反应分数。因此，对照产物在允许范围内较长，不会仅因偏离偏好长度而降低分数。四条引物自身的长度、GC、重复及结构惩罚，以及各反应的引物间互补惩罚均计入。

令 `N参考 / N替代 / N对照` 为三个反应各自不含**产物长度项**的惩罚，`L参考 / L替代` 为两种等位产物的长度惩罚，则 `P = (N参考 + N替代 + N对照)/3 + (L参考 + L替代)/2`，组分数为 `100/(1+P/25)`。当前两种等位产物同长。该分数不是三个反应分数的平均值，也不表示扩增成功率或等位基因选择性。界面评价与 TXT、HTML、CSV 导出使用同一份 SNP 专属评分说明。普通 RPA 和 LAMP 使用各自独立的评分规则。

## 完整模板位置图

普通 RPA 和 SNP RPA 候选页的灰色基线表示整理后的完整输入序列，从第 1 位到最后一位。引物箭头、扩增区间及 SNP 位置使用同一个全长坐标比例；切换候选时不会把各自的扩增片段拉伸成整条基线。每条引物单独一行，标注结合坐标及方向，基线上的着色区间表示扩增范围。SNP 标记按模板位置显示为红色。

长模板上的短引物会按比例显示得较窄，坐标文字及鼠标停留提示可用于准确确认位置。灰线是全长位置示意，不逐个显示碱基字母。

### LAMP 双链 DNA 位置图

普通 LAMP、AS-LAMP、PA-LAMP 和 mLAMP 候选结果都显示完整输入模板的双链位置图。正链为左侧 5′ 至右侧 3′，互补链反向平行；全部区段共用输入正链 `1..N` 的坐标比例，背景标出当前 F3 至 B3 的覆盖范围。切换候选不会把靶区自动拉伸成整条输入模板。

每条核心引物及找到的 LF/LB 有独立的图示行。FIP 的 F1c、F2 和 BIP 的 B1c、B2 按各自真实区间分段展示，同色及虚线表示属于同一条拼接引物。箭头表示每个区段合成序列的 5′→3′ 方向；F1c/B1c 是成环区段，图示不表示两段同时退火于线性模板。准确坐标和用途可在鼠标悬停提示、引物卡片及“靶区模板”详情中查看。

SNP 用红色标记，并显示正链坐标和两种等位碱基。AS-LAMP / mLAMP 两条等位内引物采用相同结合范围，在同一行注明共用位置；两种反应仍需分别使用。PA-LAMP 另外标示前体中的 RNA 位点及切后有效 B2，尾部和 C3 修饰作独立说明，C3 不占用模板碱基坐标。附加人为错配不当作 SNP 标红。

位置图表示原始输入模板及区段关系，不是 LAMP 最终扩增产物。较小窗口中，图示区域可纵向滚动，同时为下方引物卡片保留查看空间；长模板上的短区段保持实际比例并提供悬停说明。

## 普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP

设计模式有六项：普通 RPA、RPA SNP 选择性扩增、普通 LAMP、**AS-LAMP · 等位基因特异性**、**PA-LAMP · 引物激活型**、**mLAMP · 人工错配型（Ren 2019）**。模式名称同时显示在候选结果及导出报告中。选择 LAMP 后参数区自动切换；所有模式均提供输入、导入、候选分区及单条或整组复制；SNP 模式支持位点红色标记。每种模式都可“载入演示”；演示为随机生成的非生物来源序列。

**普通 LAMP** 每组包含 F3、B3、FIP、BIP 四条核心引物。勾选“尽可能设计环引物”时尝试增加 LF / LB，可能找到零条、一条或两条环引物，实际组成以候选清单为准。FIP 的订购序列为 `F1c + F2`，BIP 为 `B1c + B2`，不包含连接符；每个结合片段的坐标、长度、GC 和 Tm 分开显示。

**AS-LAMP** 输入一处 `[参考碱基>替代碱基]`，例如 `[G>T]`。程序可自动比较 FIP / BIP 方向，也可以指定其中一种。SNP 位于 F2 或 B2 的 3′ 最末端；每组输出两条等位内引物，以及共用的另一条内引物、F3、B3 和找到的环引物。每个候选包含完整的两种独立反应组合，每种反应只使用对应的一条等位内引物。BIP 为反向序列时，末端显示输入正链等位基因的互补碱基，但名称仍以输入等位基因命名。

可选“不加人为错配”或在 3′ 倒数第 2 / 3 位附加错配。程序枚举该位置其他三种碱基，重新检查合成引物；附加错配不是 SNP，不标红，另列原碱基、订购碱基和正链坐标。不能据排序认定其中某个错配最有选择性。当前 LAMP 不自动生成额外的通用扩增对照。

**LAMP 的“靶区模板”页显示原始 F3 至 B3 区间，不是完整扩增产物。** LAMP 会生成茎环及串联、分支产物，因此这里不给出一个固定产物长度。两种原始等位模板分别展示并标红 SNP；人为引入的错配不改写原始模板。RPA 则显示对应反应的预期扩增产物。

LAMP 支持 HTML 彩色报告、TXT 完整说明、CSV 表格及 FASTA。HTML 可离线打开并保留 SNP 红色及 mLAMP 人为错配蓝色；CSV/TXT/FASTA 为纯文本。PA-LAMP 的 FASTA 序列行为 DNA 等效序列，修饰写在标题中，不作为普通 DNA 直接订购。软件不输出临床基因型判定。

### PA-LAMP 修饰引物

选择 **PA-LAMP · 引物激活型**，输入带一处 SNP 标记的 DNA 序列。本版使用 [Du 等 PA-LAMP 原始研究](https://doi.org/10.1016/j.aca.2018.10.068)的 BIP 激活思路：`B1c + 有效 B2 DNA + RNA(SNP) + 尾部 DNA + 3′ C3 spacer`。本模式固定 BIP，停用 AS-LAMP 的末端额外错配选择。

尾部 DNA 默认 **5 nt**，包括 4 个与模板匹配的碱基和 1 个末位人为错配；允许选择 4–7 nt，依据原始补充材料的结构系列。程序枚举尾部最后一位另外三种碱基作候选筛选，具体新位点及错配类型仍需实验验证，不能当作原论文性能的复现。

RNase H2 在 RNA 的 **5′ 侧**切割，去掉 RNA、尾部和封闭基团，留下能延伸的 DNA 3′-OH。BIP 对应输入反向互补；若 SNP 的正链坐标为 `p`，切后 B2 的正链起点为 `p+1`，SNP 本身不留在活性 BIP 中。两条等位修饰 BIP 的 RNA 不同，但切后有效引物相同。每个候选分别组成两个等位反应，共用 FIP、F3、B3 和找到的环引物；需要 RNase H2 与适配的链置换聚合酶体系。

卡片和 TXT/CSV/HTML 输出完整修饰订购序列：`[rA]`、`[rC]`、`[rG]`、`[rU]` 各代表一个 RNA 核苷酸，`[C3]` 是 3′ C3 spacer。红色标出与 SNP 配对的 RNA 碱基；人为尾端错配另作说明。单条复制和整组复制保留修饰，切后活性序列独立注明。通用标记需按供应商格式确认。**FASTA 保留 A/C/G/T 序列行，在标题中同时提供 RNA 位置、C3、完整订购序列及活性序列；不能仅凭序列行订购。**

PA-LAMP 的 B2 长度和 Tm 参数指切后有效 DNA 区段。前体结构按 DNA 等效序列近似评价，未计算 RNA/DNA 双链热力学、C3 效应或 RNase H2 切割效率；分数不预测 SNP 选择性。详见 `docs/PA-LAMP方法依据.md`。所有输出均为候选，需以已知等位模板及实验对照验证。

### mLAMP · 人工错配型（Ren 2019）

选择 **mLAMP · 人工错配型（Ren 2019）**，输入一处 `[参考碱基>替代碱基]`。本模式依据 [Ren 等，ChemistrySelect 2019](https://doi.org/10.1002/slct.201802693) 主文第 1424–1425 页的 Scheme 1 / Figure 1，固定 **FIP** 方向：将 SNP 放在 FIP 的 F2 区段 **3′ 最末位**，默认在 **倒数第 3 位**加入人工错配。引物为普通 DNA；不需要 PA-LAMP 的 RNA 碱基、C3 封闭或 RNase H2 激活设计。

| mLAMP 选项 | 对应论文思路 | 用途 |
| --- | --- | --- |
| 不加人工错配（0） | Mut-FIP0 | 仅保留 SNP 末端差异，作为比较基线 |
| 倒数第 2 位 | Mut-FIP2 | 比较邻近末端的人工错配位置 |
| 倒数第 3 位（默认） | Mut-FIP3 | 论文在所测序列与条件下选用的方案 |

末端 SNP 碱基计作第 1 位。选择第 2 / 3 位方案时，目标模板与 FIP 之间保留一处人工错配，非目标模板另有一处末端 SNP 错配。设计目的是抑制非目标初始延伸、延迟背景扩增，不能解释为永远没有非目标信号。无人工错配选项是论文对照，不具有上述双错配结构。

每组输出参考与替代等位 FIP，以及共用的 BIP、F3、B3；分别组成两个独立反应。参考/替代名称跟随输入，不自动代表野生型/突变型，也不能将两个等位 FIP 混在同管视作已验证分型。进入本模式默认不加环引物；用户可启用 LF/LB，但这是程序扩展，需要另外验证。

程序会枚举人工错配位置另外三种碱基并重新评估结构。**这一枚举是程序针对新位点的探索，不是论文给出的通用碱基选择规则；排序分数不预测 SNP 选择性。** FIP 末端 SNP 标红，人工错配碱基标蓝，另列位置和替换；原始靶区模板不被改写或标蓝。引物卡片、单条/整组富文本复制和 HTML 报告均保留这两种颜色；选择“不加人工错配”时没有蓝色碱基。TXT / CSV / FASTA 保留原有序列与文字说明，不保存颜色。界面及导出均保留 mLAMP 方法身份，报告包含文献 DOI。详见 [mLAMP 方法依据](docs/mLAMP方法依据.md)。

### LAMP 设计参数与方法边界

| 参数 | 本软件默认值 |
| --- | --- |
| 每个结合片段长度 | 17–30 nt（不是整条 FIP / BIP 的长度） |
| GC | 30–75% |
| F3、B3、F2、B2 Tm（分别设置） | 各 52–68 °C |
| F1c、B1c、LF、LB Tm（分别设置） | 各 58–72 °C |
| F3 至 B3 靶区跨度（含两端） | 110–350 bp |
| F2 至 B2 跨度（含两端） | 100–220 bp |
| 输出候选 | 最多 10 组 |
| Tm 参考条件 | Na⁺ 50 mM、Mg²⁺ 4 mM、寡核苷酸 100 nM，未建模 dNTP |

表中的宽范围由普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP 共用，是本程序为了扩大候选探索空间采用的搜索边界，**不是 PrimerExplorer 官方默认值或原文实验参数**。长度与 Tm 逐区段筛选；GC 同时检查各区段及完整合成引物，连续同聚物超过 5 nt 的候选排除。默认 Tm 排序目标为 60/65°C；用户修改范围后按有效范围中点排序，任意一端无限制时回退到 60/65°C。发卡、自互补及引物对互补指标用于降分和提示，没有 ΔG 硬阈值。Tm 使用 SantaLucia 1998 最近邻参数及 Mg²⁺ 等效单价盐熵校正，按每个片段的完全匹配互补链计算；不计算人为错配与实际模板的双链 Tm，不把拼接内引物作为一个连续双链计算 Tm。该值不是建议反应温度，不能直接与采用其他离子条件的软件输出等同。

核心六区段沿输入正链顺序为 F3、F2、F1、B1c、B2c、B3c；对应订购区段需要按方向取反向互补。LF 在 F2 与 F1 之间取反向互补，LB 在 B1c 与 B2c 之间取正向序列。六区段不重叠；软件检查区段顺序、间距及整组引物的连续互补。搜索有组合上限并进行候选裁剪，不是穷举最优；分数及裁剪说明在完整报告中列出。设计阶段不进行数据库特异性检索；可在第 04 页另行启用在线 BLAST。未进行完整热力学二聚体或发卡自由能预测。

内引物预筛先保留局部指标较优的候选，再补充参考拼接 FIP/BIP 结构及 Tm 配平较优的候选，减少单区段初筛过早丢弃完整内引物较优方案的情况。F1c/B1c 每个起点各保留最多 4 个窗口，固定 F2/B2 的局部前 12 个内区段中保留最多 4 个（包含局部前 2 个）；对应外引物各最多 2 个，每侧最多 8 个布局。六区域布局每组初筛最多 8 个，裁剪时先保留局部前 4 个，再按参考结构排序补足并去重；最终完整核验仍最多 320 个，裁剪时先保留局部前 160 个，再按参考结构排序补足并去重。局部优选的保留名额可减少参考结构排序误伤人工错配候选的情况，最终评分公式不变。早期参考结构不包含 SNP/人工错配或 PA 阻断前体的全部变化；这些实际序列在最终阶段核验。早期结构有 256 nt 长度限额及计算预算，超出时回退局部指标并报告；详细规则见 [内引物预筛与候选保留](docs/LAMP默认参数与Tm模型.md#内引物预筛与候选保留)。搜索仍有限，不能保证放宽范围后所有序列的最高输出分数都不下降。

设计布局和 SNP 末端定位参考 [PrimerExplorer V5 操作说明](https://www.primerexplorer.jp/e/v5_manual/02.html)及[高级设计手册 §6.2](https://primerexplorer.jp/e/v5_manual/pdf/PrimerExplorerV5_Manual_3.pdf)。[Badolo 等 AS-LAMP 原始研究](https://link.springer.com/article/10.1186/1475-2875-11-227)在特定位点采用 BIP 末端 SNP 及邻位附加错配；[Ren 等 mLAMP 研究](https://doi.org/10.1002/slct.201802693)在所测条件下采用 FIP 末端 SNP 和倒数第 3 位人工错配。两项研究均不证明任意位点均能实现选择性扩增。当前所有输出都是待验证候选，需要用已知两种等位模板及实验对照检查交叉扩增。软件没有权威机构认证或实验性能标定。

下文的 RPA 引物长度、产物范围和四引物对照组合仅适用于 RPA。

## 界面与候选结果

程序启动时按实际 Windows 系统 DPI 缩放布局；结果卡片按字体测量尺寸，较小可用区域支持滚动。SNP 标记使用 `[参考碱基>替代碱基]`，例如 `[A>C]`、`[G>T]` 或 `[C>A]`；支持 A、C、G、T 中任意两种不同碱基的单碱基替换，每次一处。

候选结果按左右分区展示：**左侧选择候选组，右侧显示位置图及详情**。切换候选时，位置图和三个详情页同步更新。RPA 的详情页如下；LAMP 将“扩增产物”替换为“靶区模板”。

| 详情页 | 内容 |
| --- | --- |
| 引物 | 每条引物独立显示卡片，包含名称、用途、5′→3′ 序列、坐标、长度、GC 和 Tm 估算；普通 RPA 显示 F/R 两条，SNP RPA 显示四条 |
| 扩增产物 | 每条预期产物独立显示卡片，包含对应反应、坐标、长度和序列；SNP RPA 分别显示两种等位反应产物，以及对照反应在参考、替代模板上的两种产物 |
| 评价与说明 | 集中查看结构指标、候选提示、输入及搜索说明、设计策略与方法限制 |

引物和产物卡片均可**单条复制序列**，同时提供富文本和纯文本：支持富文本的编辑器可保留 SNP 红色及 RPA SNP / mLAMP 人为错配蓝色标记，纯文本只包含碱基序列。页面提供全组引物复制及结果导出功能。

SNP 位点在引物及产物序列中标红；RPA SNP 的人为附加错配在两条等位正向引物中标蓝，两种等位反应预期产物中由这些引物引入的对应碱基也标蓝，并另列坐标和替换说明。位置图用于查看结合方向和相对位置，精确坐标以各卡片的数据为准。SNP RPA 的四张产物卡对应**三种独立反应**：共用对照在两种模板上的产物分别展示，不增加第四种反应。

### SNP 红色、人为错配蓝色与导出

- 结果界面的引物和扩增产物序列中，**SNP 碱基显示为红色**。SNP RPA 的两条等位正向引物标记 3′ 末端；参考、替代及两种共用对照产物按各自产物起点计算 SNP 位置。SNP LAMP 标记等位内引物的 SNP 碱基及两种靶区模板中的对应碱基。
- R_common 和 F_control 不覆盖当前 SNP，因此不标红。RPA SNP / mLAMP 人为附加错配标蓝，界面另列位置及替换碱基，RPA 文本报告保留 `*` 注释。共用引物、对照产物及原始模板不标蓝；不加人为错配时无蓝色标记。
- SNP 模式“导出结果”默认生成 **HTML 彩色报告**，用浏览器打开即可保留 SNP 红色及 RPA SNP / mLAMP 人为错配蓝色。报告完全自包含，可离线打开，无外部资源请求。
- “复制选中组 4 条引物”同时提供纯文本及富文本；粘贴到支持富文本的编辑器并保留源格式时可保留红色及蓝色。粘贴为纯文本时只保留原序列。
- CSV、TXT、FASTA 是纯文本格式，不保存字体颜色，序列不插入颜色代码。PA-LAMP 的 TXT/CSV 保留 RNA/C3 修饰，FASTA 以 DNA 等效序列加标题元信息保存。

## 筛选参数的“无限制”选项

每个筛选数字旁提供独立的“无限制”复选框。勾选后暂停使用该项数值，取消勾选可恢复原值；上下限可分别放开。“恢复默认参数”会清除对应模式的全部无限制选项。

| 模式 | 可分别取消的筛选项 |
| --- | --- |
| 普通 RPA / RPA SNP | 引物最短、最长；GC 最低、最高；产物最短、最长；偏好产物长度，共 7 项 |
| 普通 LAMP / AS-LAMP / PA-LAMP / mLAMP | 片段最短、最长；GC 最低、最高；F3–B3 与 F2–B2 跨度上下限；8 个区段各自 Tm 上下限，共 24 项 |

RPA 的偏好产物长度设为无限制时，产物长度偏好惩罚为零；其他组成和结构评分照常保留。输出候选数量继续使用原设置。界面“本次参数”与 TXT / HTML / CSV 报告均记录每项无限制状态。

“无限制”关闭相应的用户筛选边界；引物仍需位于输入序列内，RPA 引物至少有一个碱基，LAMP 最近邻 Tm 计算至少需要两个碱基。LAMP 的六区顺序、非重叠及现有间距规则、歧义/同聚物筛选、SNP 定位和 PA 尾部构型继续适用。输入长度上限仍为 20,000 nt。靶区坐标继续用“包围指定靶区”开关控制，PA 尾部长度、SNP 策略和是否使用环引物是方法设置，不作为无限制筛选项。

长度范围放开后会扩大搜索范围；程序仍采用有限的候选保留和组合搜索，宽范围会使用采样，并在结果说明及搜索裁剪状态中记录。无限制不表示穷举所有组合，也不保证一定能找到候选。RPA 与 LAMP 两套筛选开关分别保留，切换模式时不会相互覆盖。

## RPA SNP 选择性扩增

1. 把“设计模式”切换为 **RPA SNP 选择性扩增**。
2. 在完整 DNA 序列的一处 SNP 使用 `[参考碱基>替代碱基]` 格式。例 `…GACT[A>C]TAGC…` 或 `…GACT[G>T]TAGC…` 仅演示写法，实际须输入足够的上下游序列；也可点击“载入演示”。
3. SNP 标记整体计作一个碱基，程序自动给出坐标。普通模式的“包围指定靶区”此时停用。
4. 默认采用“仅 SNP 末端差异（基线）”。也可选择在倒数第 2 或第 3 位增加人为错配的探索策略，程序枚举该位置另外三种碱基。这里末端碱基计作第 1 位。
5. 每个候选组包含以下四条引物，均可复制或导出。

| 引物 | 位置与用途 |
| --- | --- |
| F_ref（例如 F_A） | 3′ 最后一位落在 SNP，末端为参考等位基因 A |
| F_alt（例如 F_C） | 与 F_ref 采用相同结合坐标，3′ 最后一位为替代等位基因 C |
| R_common | SNP 下游共用反向引物，不跨该 SNP |
| F_control | SNP 上游对照正向引物，不跨该 SNP，与 R_common 配对 |

**按三种独立反应使用**：`F_ref + R_common`、`F_alt + R_common`、`F_control + R_common`。本版没有验证四条引物的单管体系，不能把普通对照扩增信号直接当作等位基因信号。A/C 仅是输入定义的参考/替代标签，不自动代表正常/致病。

所有四条引物均须满足界面长度和 GC 范围；两种等位反应及共用对照的产物也均须满足产物范围。对照产物长度仅用于范围硬筛选，不参与偏好长度评分。F_control 的起点要求位于等位正向引物起点上游，且末端位于 SNP 上游，因此对照片段更长。F_control 和等位正向引物结合区可以部分重叠，因为按独立反应使用。过短的侧翼或过窄的产物范围可能没有符合条件的完整四引物组合。

附加错配在两条等位正向引物中采用同一个替换，不改变 SNP 末端碱基；修改后重新检查组成与结构。报告同时标明模板碱基、合成引物碱基和坐标。预期扩增产物包含合成引物引入的碱基，代表**若反应发生扩增时**的序列，不预测扩增一定发生。共用对照报告参考和替代模板的两条产物。

仅接受一处不同 A/C/G/T 之间的单碱基替换；不支持 `[A>A]`、插入缺失、多个 SNP 或 SNP 位点的歧义碱基。FASTA 标题中的方括号不会被当作位点标记。外部的 IUPAC 歧义碱基按普通模式规则保留；结合窗口含歧义时跳过。

### SNP 方法依据与边界

RPA 对错配有容忍性，不能仅凭 3′ 端不同一个碱基就断言“只扩增目标等位基因”。[Higgins 等的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179515/)说明错配位置与碱基类型共同影响表现。[Daher 等的原始研究](https://pubmed.ncbi.nlm.nih.gov/25481659/)也说明多个错配的位置分布会影响扩增。

[Chang 等 2024 年的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11334763/)在特定位点和检测体系中结合 LNA 修饰及人为错配获得判别；不同位点需要不同策略。本软件目前生成**普通 DNA 引物**，没有加入 LNA，也没有复现或验证其位点特异体系。倒数第 2/3 位的附加错配均为候选探索，不能视为通用有效规则；它也可能损害目标扩增。

SNP 排序仅依据序列组成、单引物长度、重复、连续互补与等位产物长度等启发式指标，不预测等位基因区分率、灵敏度或检测限。需对两种已知等位基因模板及相应对照进行选择性验证。设计阶段不进行数据库检索；另行启用 BLAST 后可检查所选库中的近似匹配。未验证临床性能，不输出诊断或基因型判定。

SNP 模式复用下文的单引物惩罚与引物间互补惩罚，三种反应的这些惩罚取平均；另加两种等位反应产物长度惩罚的平均值。每种等位产物的长度惩罚为 `8 × |等位产物长度 − 偏好长度| / max(1, 最长产物 − 最短产物)`，对照产物不产生该项惩罚。总惩罚 `P = (N参考 + N替代 + N对照)/3 + (L参考 + L替代)/2`，组分数为 `100/(1+P/25)`；`N` 包含单条引物自身的长度惩罚。共用反向和对照正向各最多保留 1,000 条候选；等位正向/共用反向组合最多进一步评估 12,000 套，各套对初评较优的前 6 条合格对照正向做成对互补计算。对照初评和优选均不使用对照产物长度惩罚。搜索裁剪会明确说明。输出优先分散共用反向结合位置，故不是所有组合按分数的穷举排名。

## 启动与使用

1. 双击 `dist-v1.0\Primer Designer.exe`。也可使用已更新的桌面 `Primer Designer` 快捷方式。适用于 64 位 Windows 10 / 11，使用系统 .NET Framework 4.x，无需 Python、安装包或账户。
2. 粘贴纯序列，或导入单条 FASTA / TXT。可点击“载入演示”试用；演示序列由固定随机种子生成，没有生物来源。
3. 保留默认参数，或按实验需求修改。点击“开始设计”。
4. 在“候选结果”的左侧选择候选，右侧通过位置图及“引物 / 扩增产物 / 评价与说明”三个页签查看详情。
5. 用卡片上的复制按钮复制单条引物或产物序列；页面底部可复制全组引物。“导出结果”可保存完整 TXT 报告、Excel 可打开的 UTF-8 CSV 或引物 FASTA；SNP 模式另支持 HTML 彩色报告。

所有引物均按 **5′→3′** 输出。反向引物已取反向互补。坐标均对应输入正链，从 **1** 开始，起点与终点均包含；RPA 产物长度包含两端引物结合区。

普通模式的“包围指定靶区”可用于要求产物覆盖指定片段。例如靶区 200–225 意味着正向引物终点必须小于 200，反向引物结合区起点必须大于 225。SNP 候选设计请使用独立 SNP 模式。

## 输入规则

- 每次一条线性序列，上限 20,000 nt；FASTA 中出现第二条记录会报错，防止误拼接。
- 自动转大写并清理空白、数字行号。U 转为 T 并提示；不会自动决定反转录体系。
- 支持 IUPAC 歧义字符 `RYSWKMBDHVN`，保留其坐标；引物不会跨越这些位点。扩增片段内部可以含歧义位点，并提示。
- 不接受缺口 `-`、标点或非 IUPAC 字符。输入应为序列，不应混入注释正文。
- 修改输入或参数后，会清除旧结果，避免导出与当前输入不符的数据。

| 输出 | 10 对，尽量分散结合位置 |
| 最长同聚物 | 5 nt；更长的窗口排除 |

参考 Abbott / TwistDx 官方 [TwistAmp Assay Design Manual，INASDM Rev 1，§2](https://www.globalpointofcare.abbott/content/dam/ardx/globalpointofcare/lp/2025/twistdx/support/docs/manuals/INASDM%20v1.0%20TwistAmp%20DNA%20Amplification%20Kits%20-%20Assay%20Design%20Manual%20INASDM.pdf)（2026-09-20 核验）。长度、GC 和产物范围是设计起点；序列本身不能可靠预测 RPA 性能，需筛选多条候选。结构阈值、权重和搜索上限均为本软件的工程选择，未作实验标定。

自定义允许引物 20–60 nt、产物最长 5,000 bp、输出 1–50 对。超出默认引物长度或产物超过 500 bp 会提示，允许输入不代表推荐或验证通过。最短产物须至少能容纳两条最短引物，偏好长度须在产物区间内。

## 普通 RPA 评分含义与计算限制

以下配对评分公式适用于普通 RPA。RPA SNP 模式使用上文的专属聚合公式，仅将两种等位产物长度计入偏好长度评分；LAMP 使用独立评分规则。

软件先按长度、GC、同聚物、方向、靶区与产物长度做硬筛选，再按下列启发式惩罚排序。所有引物必须完全匹配输入中的确定碱基；不会设计简并引物。

单引物惩罚为：

```text
0.12 × |GC百分比 − 50|
+ 0.3 × |长度 − clamp(32, 最短引物, 最长引物)|
+ 1.5 × max(0, 最长同聚物 − 3)
+ 0.5 × max(0, 最长短串联重复跨度 − 8)
+ 0.6 × max(0, 连续自互补长度 − 3)
+ 1.8 × max(0, 涉及3′端的连续自互补长度 − 2)
+ 1.2 × max(0, 发卡茎长度 − 3)
```

配对惩罚在两条引物惩罚之和的基础上加：

```text
8 × |产物长度 − 偏好长度| / max(1, 最长产物 − 最短产物)
+ 0.8 × max(0, 引物间连续互补长度 − 3)
+ 2.5 × max(0, 引物间涉及3′端的连续互补长度 − 2)
```

显示分数为 `100 / (1 + 总惩罚 / 25)`，越高越优先作为实验筛选候选，**没有成功率含义**。GC 50%、长度 32 nt 等排序偏好不代表 RPA 的普适最优值。

短串联重复指标统计 2–4 nt 模体至少连续 3 次完整重复的最长跨度（nt）；达到 12 nt 时提示，不硬性排除。互补指标为无错配、无缺口的最长连续 Watson–Crick 互补长度；3′ 指任一引物的末端参与该连续配对。发卡最短环为 3 nt。本版未计算 ΔG，不考虑盐浓度、镁离子浓度、错配、鼓包等因素，不能代替完整热力学结构分析。

Tm 仅显示经验公式 `64.9 + 41 × (G+C数量 − 16.4) / 长度`，不用于排序、过滤或建议 RPA 反应温度。

为使本地程序可响应，单方向超过 4,000 个候选时，每 20 nt 位置分箱保留初筛较优候选；符合位置条件的配对超过 30,000 时，只对初评较优的 30,000 对计算交叉互补。因此不是穷举全部组合，也不保证找到全局最优解。发生裁剪会在界面和完整报告中说明。两对产物起、终点差均小于 6 nt 时视为近似重复，相同 F/R 序列组合只保留一次；实际结果可能少于请求数量。

RPA 设计阶段的重复结合提示只检查入选引物及其反向互补在当前输入模板中的重复完全匹配；LAMP 设计阶段没有该检查。**设计阶段本身不进行数据库检索或带错配的脱靶检索。** 不支持 exo/nfo 检测探针、甲基化转化模型、多重扩增、环形跨原点设计。可选 BLAST 需在独立页面启用并确认上传，提供所选数据库范围内的局部比对与潜在组合初筛；结果单独导出，不包含在原引物设计报告中。

## 从源码构建、验证与打包

源码使用 C# 5 与 .NET Framework / Windows Forms，仅使用系统库，无 NuGet 依赖。在工作区根目录依次执行以下命令；生成演示与打包使用当前 EXE，不依赖其他版本的发行目录。

构建默认输出到 `dist-v1.0`；可通过 `-OutputDirectory` 指定其他目录。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

验证默认使用当前发布，报告输出到 `build/checks`。`-Ui` 同时运行界面和位置图检查；可通过 `-ApplicationPath` 指定待验证的 EXE，通过 `-OutputDirectory` 指定报告目录。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test.ps1 -Ui
```

从当前 EXE 生成普通 RPA、SNP RPA、普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP 演示文件，默认保存到 `dist-v1.0`。打包脚本使用该发行目录，并将根目录源码、构建入口、说明文档、脚本、界面检查和图标整理到发行目录的 `source/`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\GenerateExamples.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1
```

程序正在运行时，可为构建指定独立目录，并使用验证脚本的 `-ApplicationPath` 检查该目录内的 EXE，避免覆盖正在使用的文件。直接打开 `dist-v1.0\Primer Designer.exe` 可运行本版；构建脚本本身不更新桌面快捷方式，发布时需核对其目标路径。

打包会核对当前 EXE 与测试报告的 SHA256；报告不匹配时会停止。发布完成后，可预览并清理旧发行版和可重新生成的构建文件；源码、图标、当前发行版和 Git 元数据保留：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Clean.ps1 -BuildArtifacts -WhatIf
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Clean.ps1 -BuildArtifacts
```

清理后若要再次打包，请先重新运行验证命令，生成新的 `build/checks` 报告。

## 验证范围

验证集合覆盖普通 RPA、SNP RPA、SNP 标红、普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP 的核心逻辑，并提供界面及双链位置图检查。重新构建后使用上述验证脚本复核；自检数量、界面断言数量及通过情况以本次生成的报告为准。

自检覆盖序列处理、方向、坐标、参数约束、报告、导出与取消。SNP 长度评分检查覆盖：同等引物质量下对照产物长短不改变分数；偏好长度只影响等位产物评分；对照超出长度范围仍被排除；普通 RPA 保留自身的长度评分。LAMP 检查还包括所有 12 种单碱基替换的两个内引物方向、六区段坐标、环引物方向、最近邻 Tm 手算参考值及附加错配。mLAMP 检查包括固定 FIP、默认第 3 位人工错配、0 / 2 位比较选项、普通 DNA 序列、两种独立反应及导出方法身份。

界面与位置图检查覆盖全长坐标映射、双链方向、复合内引物区段、PA 前体与有效 B2、实际箭头比例、候选切换、SNP 位置、20,000 nt 长模板、边界和窄窗口，以及最小窗口布局、模式切换和 SNP 字符标色；断言数量对应本机 144 DPI。检查使用隐藏窗口，部分原生文本控件可能不出现在截图中，因此同时检查控件内容和尺寸；另在不显示桌面窗口的独立控件中检查原生滚动能到达图尾且没有横向溢出。这些检查不等同于人工交互验收，也不代表湿实验验证。

演示序列为固定随机种子生成的非生物来源序列。LAMP 演示为 800 nt，SNP LAMP 演示在第 333 位使用 `[T>C]`；演示报告用于检查软件行为，不涉及真实基因或实验性能证明。
