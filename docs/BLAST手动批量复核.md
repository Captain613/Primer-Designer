# BLAST 手动批量复核（v1.0.6）

第 04 页把区段 FASTA 导出和 XML 批量复核整合在同一程序中。程序不再自动提交或等待在线 BLAST；网页检索由用户操作。

## 导出并进行网页 BLAST

1. 完成引物设计并选中一组，打开“04 BLAST 手动复核”，点击“载入当前候选”。
2. 点击“复制区段 FASTA”或“导出区段 FASTA…”。预览和导出的内容为实际碱基序列，保留 SNP 和人为错配。
3. 点击“打开 NCBI（推荐设置）”，打开预填短序列参数的 Nucleotide BLAST 表单。把完整 FASTA 粘贴到查询框或上传该文件，再手动提交。
4. 默认使用人类与 RefSeq Genome Database（refseq_genomes）。若目标为其他物种，先在“NCBI 网页参数与说明”页修改“网页目标物种”，再打开网页；也可在 NCBI 页面修改。物种设置只影响下次打开网页，不能修改已下载 XML 的搜索范围。
5. 展开网页 Algorithm parameters，核对下表的值。链接采用 NCBI 网页书签格式以保留数据库与筛选预设；NCBI 可能改版，因此以实际页面和提交后的 Search Summary 为准。
6. 下载全部查询的完整 XML / XML2。若下载文件是 ZIP，先解压。仅下载当前查询或复制网页上某一条比对不能代替批量完整结果。

## 网页推荐参数的含义

第 04 页的“NCBI 网页参数与说明”标签提供可滚动的完整说明，同时解释本地复核的区段、坐标、错配、跨度及参考缓存选项。

| NCBI 网页选项 | 预填值 | 含义 |
| --- | --- | --- |
| Database | RefSeq Genome Database（refseq_genomes） | 查找目标物种基因组结合位置；RefSeq RNA 不能替代基因组 DNA 复核。 |
| Organism | Homo sapiens (taxid:9606) | 仅检查人类记录；可修改，不评价范围外物种。 |
| Program | Somewhat similar sequences (blastn) | BLASTN 短区段搜索。 |
| Short input adjustment | 勾选 | 允许按短查询自动调整参数。 |
| Word size | 7 | 连续匹配种子长度，不是允许错配数。 |
| Expect threshold | 1000 | 较宽的短序列统计报告阈值，不是本地布局跨度或扩增成功率。 |
| Match/Mismatch | 1/−3 | 匹配奖励、错配罚分，不是本地每区段最多错配。 |
| Gap costs | 5/2 | 插入缺失的开口与延伸罚分，避免不兼容的 0/0。 |
| Max target sequences | 1000 | 每条查询最多返回的数据库目标记录数；一条染色体记录可有多个局部命中。 |
| Max matches in a query range | 0 | 关闭按查询范围的命中裁剪；不是不返回结果。 |
| Low complexity、Species-specific repeats、Mask for lookup table only、Lower case masking | 不勾选 | 不对短查询执行这些屏蔽。 |
| Query subrange、额外 Entrez 限制、Align two or more sequences | 留空 / 不启用 | 查询完整区段并搜索数据库。 |
| 结果显示 | HTML、新版视图、图形概览及 Pairwise | 常规网页结果界面；显示格式不改变搜索命中，下载时仍选 XML/XML2。 |

链接只携带这些网页设置，不包含区段序列、查询标题、本地文件路径、预期坐标或自动提交命令。人类基因组预设适用于本次流程；更换实验对象时需按目标物种调整数据库覆盖。

### 如果先显示传统结果页

v1.0.6 的预设链接补上 `ADV_VIEW=on`，保留 NCBI 当前表单的新版结果显示选择。已有结果可点击页面顶部 “Click here to use the new BLAST results page” 切换，不需要重新检索。显示视图不改变搜索命中；批量复核仍使用全部查询的完整 XML/XML2。

### 如果结果显示为纯文本

v1.0.4 的预设链接遗漏结果显示的隐藏参数，可能出现 `Invalid FORMAT_TYPE '' was used`，随后以 Text 显示结果。v1.0.5 已明确预填 HTML 以及完整显示默认值，修复此问题。

此提示表示显示格式无效；如果已有 RID 和比对结果，搜索已经完成。可使用同一 RID 请求 HTML 结果，无需重新搜索。格式转换不会改变已保存的搜索命中；下载批量复核文件时仍需使用全部查询的完整 XML/XML2，不要把纯文本文件改名为 XML。

## 在程序中复核

1. 选择“完整 BLAST XML”和与该次查询对应的“区段 FASTA”。路径也可手动粘贴。导出 FASTA 后程序会自动填入该文件路径。
2. 可填写预期参考序列登录号及版本，例如 NC_000010.11；选择用于定位的区段 F2、B2、F 或 R，填写该实际区段 3′最末位的参考基因组坐标。反向区段的 3′端是其低坐标端。
3. 输入模板中的相对坐标不能直接当作参考基因组坐标。不确定时留空登录号、将坐标设为 0，所有组合会列为待确认。
4. 初始计算筛查范围为每区段最多 4 处错配、布局跨度最多 1000 bp，可调整。这些参数不是实验判断标准。
5. 没有参考缓存时，保持“联网补齐公开参考区段”勾选。联网读取公开参考序列，不重新上传引物。缓存存在时可以关闭联网后运行。
6. 点击“开始批量复核”；完成后点击“打开复核报告”。HTML 与 TXT 保存在程序目录的 BLAST复核/结果/复核_时间；缓存保存在 BLAST复核/参考缓存。

可直接导入已有文件，不要求先在当前程序设计候选。复核报告记录的是所选文件；它不会自动代表当前候选列表中的其他组。

## FASTA 标题与反应组合

LAMP 核心区段为 F3、F2、F1c、B1c、B2、B3。完整 FIP/BIP 的拼接序列不作为一个连续基因组结合区段。RPA 使用 F/R；SNP RPA 的参考、替代和对照反应分别定义。

程序导出的标题包含组名、区段名称和 reactions 信息，例如 `mLAMP_001_F2_ref reactions=ref`、`mLAMP_001_F3_common reactions=ref,alt`。使用共享区段只写一条记录；相同角色、相同序列共用查询。不同角色需要各自记录，方便正确定位。标题、反应信息和碱基在网页提交与复核时都应保持一致。

reactions 信息用来避免把不同反应的区段混配。它支持 FIP 或 BIP 的等位版本。已有不含该信息的文件仍可使用 `Set01_F3_common` 等标题：每组须具有完整核心角色，只允许一个角色有多条版本；多个角色同时有多条版本时需要 reactions 明确指定真实反应组合。

LF/LB 是辅助查询，不作为六核心区段组合的必要条件。PA-LAMP 使用切后有效 DNA 区段，此项检查不评价 RNA/C3、RNase H2 激活、前体结合或等位选择性。

## 怎样理解结果

- 预期位点组合：参考登录号和所选区段末位坐标都符合填写的预期位置。
- 其他需复核组合：满足顺序、方向、不重叠与跨度条件，但未确认是预期位置。没有填写完整预期位置时，也会进入这一类。
- 全长错配位置：从实际区段 5′端第 1 位起算。完整参考比较会补齐 BLAST 截短的末端；人为错配不自动修回参考碱基。
- 关键末端：F1c/B1c 提示 5′成环端，其余核心引物提示 3′端。仅供阅读，不作为扩增能力判据。
- 未完成项：查询记录缺失、参考获取失败、参考区段含 N 或搜索达到上限时需要复核；不能将其解释为无命中或通过。

程序先根据 BLAST 返回的局部命中筛选候选，再对完整参考序列进行无插入缺失比较。每组候选区段依据外侧 F3/F 锚点展开，上限由布局跨度决定。区域、组合和搜索步数均有限额，超过时在报告提示。

本次数据库覆盖、BLAST 种子漏检、返回上限、输入多态性、含插入缺失的结合、超过当前错配或跨度限制的结合及其他非特异扩增机制可能影响结论。没有检出其他组合不能证明无脱靶。此工具不计算完整引物的二聚体/发卡自由能，不预测无模板扩增或等位区分效果。
