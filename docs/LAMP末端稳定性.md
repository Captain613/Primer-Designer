# LAMP 输出后末端稳定性检查

结果生成后自动显示于每条引物的详情，单条结果仅列区段、检查端、末端序列及 ΔG°37 数值，不在每个数值后重复解释。统一说明放在界面引物清单和 TXT/HTML 报告前面。CSV 的“末端6nt稳定性_序列及DeltaG37”列只显示结果，“末端稳定性模型与限制”列仅在第一条数据行填写统一说明。订购序列、FASTA、候选搜索、筛选与排序保持原有逻辑。

## 模型与参考条件

使用 [SantaLucia 1998](https://doi.org/10.1073/pnas.95.4.1460) 统一最近邻参数中直接列出的 ΔG°37，单位 kcal/mol。固定 37°C、1 M Na⁺，模型为完全匹配 DNA 短双链。不使用当前 Tm 的 Na⁺、Mg²⁺、寡核苷酸浓度，不附加盐校正，不将其解释为 LAMP 反应温度下的自由能。

计算为末端六碱基的五个相邻堆积项之和，加短双链两个端点的起始项和适用的对称性修正。

| 堆积（合成方向） | ΔG°37 |
|---|---:|
| AA / TT | −1.00 |
| AT | −0.88 |
| TA | −0.58 |
| CA / TG | −1.45 |
| GT / AC | −1.44 |
| CT / AG | −1.28 |
| GA / TC | −1.30 |
| CG | −2.17 |
| GC | −2.24 |
| GG / CC | −1.84 |

每个 A/T 端点加 1.03，每个 G/C 端点加 0.98；六碱基片段与自身反向互补一致时加 0.43。直接采用上述表值，避免由已舍入的 ΔH/ΔS 反算引入额外差异。代码以百分之一 kcal/mol 的整数累加再转换为小数，阈值判断包含等于 −5.00 的情况。

校验样例：GCGCGC = −8.67（含对称性修正），ATATAT = −1.31，AAAAAA = −2.94，AGGCTT = −5.58。

## 窗口与提示

[PrimerExplorer V5 附录](https://primerexplorer.jp/e/v5_manual/03.html) 使用末端 6 bp，并将 ΔG ≤ −5 kcal/mol 作为可随条件调整的稳定性参考标准。本版固定该参考阈值，只提示、不作为通过实验验证的判定。

- FIP 的 F2、BIP 的 B2、F3、B3、LF、LB：按实际合成方向取最后六碱基。
- F1c、B1c：取实际合成方向的前六碱基。此项单独标作 5′ 端。
- 短于六碱基、含非 A/C/G/T 字符的区段不计算；不跨越拼接区段补足窗口。
- AS-LAMP/mLAMP：若该窗口包含人工错配，仍显示合成序列的完全互补参考 ΔG，统一说明中注明“实际错配结合未评估”，不能据阈值判断真实错配结合是否达标。另一等位模板造成的 SNP 错配结合也未计算，不能用于宣称等位选择性。
- PA-LAMP 修饰 BIP：只读取切后有效 DNA 区段。RNA、尾部 DNA、C3 前体的稳定性及酶切效率不在本功能范围内。

统一说明解释 ≤ −5.00 的参考标准及末端偏弱、错配和 PA-LAMP 的含义，每条 ΔG 后不重复附加判断说明。末端 ΔG°37 不代表二聚体/发卡自由能，不替代现有结构启发式检查。RPA 未引入 LAMP 阈值。
