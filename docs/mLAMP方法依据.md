# mLAMP 方法依据与程序实现范围

## 原始来源

Ren Y. 等，*One-Step Quantitative Single Nucleotide Polymorphism (SNP) Diagnosis By Modified Loop-Mediated Isothermal Amplification (mLAMP)*，ChemistrySelect，2019。[DOI：10.1002/slct.201802693](https://doi.org/10.1002/slct.201802693)。本功能的结构依据为用户提供的主文，重点为第 1424–1425 页的 Scheme 1 与 Figure 1；2026-10-09 进一步核对补充材料 Table S1 的 TP53 引物与程序搜索参数。没有据此声称复现原文全部实验条件或性能。

这里的 modified 指在 DNA 引物中人为改变碱基。该方法不使用 RNase H2 激活、RNA 位点或 3′ C3 封闭；这些结构属于程序中的另一个 PA-LAMP 模式。

## 论文的设计逻辑

LAMP 使用 FIP、BIP、F3、B3 四条核心引物识别六个区域。作者将 SNP 放在 FIP 的 F2 区段 3′ 最末位，使等位 FIP 的末端分别与对应模板匹配。单个末端错配仍可能被聚合酶延伸，随后少量错误产物可能被 LAMP 放大，因此作者进一步比较末端附近的人为错配。

```text
FIP：5′—F1c—[F2 主体 … X—N—S]—3′
                            3  2  1   从 3′ 端计数

S：识别 SNP；目标模板匹配，另一等位模板错配
X：默认人工错配位置；对两种模板均保留人为错配
N：正常配对位置
```

图中结构对应倒数第 3 位方案。对于该 FIP，目标模板仍含一处人工错配；非目标模板同时含人工错配及末端 SNP 错配。论文 Figure 1 比较无额外错配的 Mut-FIP0、倒数第 2 位的 Mut-FIP2 和倒数第 3 位的 Mut-FIP3，并在所测靶点与条件下选择 Mut-FIP3。这个结果支持该实例中第 3 位较合适，不能证明第 3 位对任意新 SNP 都最优。

背景扩增受到抑制和延迟，不等于被绝对阻断。论文中非目标模板仍可出现较晚的信号，因此本软件不凭序列或分数判定基因型，也不把终点有无信号作为通用判别规则。论文的一步检测指扩增与检测结合，两个等位 FIP 应分别用于独立反应。

## 程序提供的选项

| 项目 | 实现 |
| --- | --- |
| 方法身份 | `SnpMethod = "mLAMP"`；显示 mLAMP · 人工错配型（Ren 2019） |
| 特异内引物 | 固定 FIP；F2 的 3′ 最末位落在输入 SNP |
| 人工错配位置 | 默认倒数第 3 位；可选第 2 位，或 0 表示不加人工错配的论文对照 |
| 人工错配碱基 | 枚举原匹配碱基以外的三种 A/C/G/T，并重新检查合成序列 |
| 等位反应 | 参考 FIP + 共用 BIP/F3/B3，与替代 FIP + 共用 BIP/F3/B3 分开配制 |
| 环引物 | 默认关闭；用户启用时尝试 LF/LB，属于程序扩展 |
| 订购引物 | 普通 DNA，5′→3′；不添加 RNA 或 C3 |
| 显示与导出 | SNP 标红，人工错配标蓝并另列坐标及替换；界面、富文本复制及 HTML 保留颜色；TXT/CSV/FASTA 为纯文本，均标明 mLAMP 与文献 DOI |

参考/替代仅表示输入定义的两个等位基因，不自动代表野生型/突变型。两条等位 FIP 采用相同结合范围及同一人工错配替换，只在末端 SNP 碱基上不同。非特异的共用引物避开当前 SNP。程序没有自动增加通用扩增对照，也没有将两个等位 FIP 混入同一反应的验证体系。

倒数第 3 位人工错配的正链坐标为 SNP 坐标减 2；第 2 位为 SNP 坐标减 1。末端碱基算第 1 位。人工错配只改变订购引物，保留原始输入与两种靶区模板。F3 至 B3 的区间用于定位，不是固定长度的 LAMP 最终产物。

## 当前共享 LAMP 搜索范围

mLAMP 与普通 LAMP、AS-LAMP、PA-LAMP 共用以下默认长度、GC、Tm 和跨度范围。切换至 mLAMP 固定 FIP 方向、默认第 3 位人工错配并关闭环引物；已经手动修改的数值范围不会因模式切换而自动重设。

| 参数 | 当前默认范围 |
|---|---|
| 每个结合片段长度 | 17–30 nt；不是整条 FIP/BIP 长度 |
| GC | 30–75%，逐区段及完整合成引物均检查 |
| F3 / B3 / F2 / B2 Tm | 各 52–68 °C，分别设置 |
| F1c / B1c / LF / LB Tm | 各 58–72 °C，分别设置；LF/LB 仅启用环引物时使用 |
| F2 至 B2 外缘跨度 | 100–220 nt，包含两端 |
| F3 至 B3 外缘跨度 | 110–350 nt，包含两端 |

此次扩大范围始于 TP53 实例的比较：Table S1 的 B3 为 17 nt；F2 按本程序 Na⁺ 50 mM、Mg²⁺ 4 mM、寡核苷酸 100 nM 的完全匹配参考模型计算，Tm 约为 66.4/67.3 °C。此前每段 18–27 nt、F2 Tm 55–65 °C 的范围会排除这些特征。论文没有给出上述计算 Tm、各区段的通用 Tm 上下限或 ΔG 阈值；当前更宽范围是软件候选探索的工程选择。调整前后数值见 [LAMP 默认参数与 Tm 模型](LAMP默认参数与Tm模型.md)。

默认 Tm 范围中点仍为 60/65 °C，GC 50%、片段长度 22 nt、F2–B2 跨度 140 nt 和 F3–B3 跨度 200 nt 继续用于排序。六区段不重叠、对应 5′ 端距离 40–60 nt 及外侧净间隙 0–60 nt 的硬性布局要求继续生效。人工改写前的模板匹配 F2 与改写后的两个等位 F2 均须满足本次设置的 GC、Tm 和同聚物检查；发卡与引物互补采用启发式降分和提示，没有 ΔG 硬阈值。

## 拼接内引物结构预筛

仅按 B1c 自身的 GC、长度和 Tm 保留前两条，可能排除与同一 B2 拼接后发卡较少的 BIP。2026-10-09 的搜索调整将 F1c/B1c 在每个起点保留的窗口增至 4 个；对固定 F2/B2，从局部前 12 个合格内区段中保留局部前 2 个，再按参考拼接内引物结构及 Tm 配平补充至最多 4 个。对应 F3/B3 仍各保留 2 个，每侧最多形成 8 个布局；每个六区域布局分组由最多 3 个增至 8 个，裁剪时先保留局部前 4 个，再按参考结构排序补足并去重。最终完整核验仍最多 320 个布局，裁剪时先保留局部前 160 个，再按参考结构排序补足并去重。重叠候选只占一个名额，结构排序可以继续补充到限额，不是两种排序各截取固定一半后简单合并。最终评分公式不变。

这一步结构预筛按人工改写前的参考 FIP/BIP 评价，随后才枚举实际 SNP 等位与人工错配。参考结构优选与局部优选同时保留，减少参考 FIP 结构排序不利、但人工错配后表现较优的候选被全部裁掉的情况。两条等位 FIP、共用 BIP、F3、B3，以及启用时的 LF/LB，在最终阶段按实际序列评价自结构与各独立反应中的引物间互补。预筛结构优选不是对错配选择性或最终分数的预测。

程序共用序列结构指标缓存；早期仅核验不超过 256 nt 的拼接序列，并采用每次设计 100,000,000 个估算计算单位的预算（单次为 `4×序列长度²`）。超过早期长度限额或预算时，预筛回退局部指标并报告该情况，候选长度仍按用户设置筛选。详细计算策略见 [LAMP 默认参数与 Tm 模型](LAMP默认参数与Tm模型.md#内引物预筛与候选保留)。这些保留数和预算属于软件有限搜索，仍可能遗漏合适组合；不能保证所有序列在放宽范围后输出最高分数都不下降，也不是穷举全局最优或湿实验验证。

## 论文依据与程序探索的界线

论文提供的是特定序列和条件下的人工错配位置比较，并未给出任意 SNP 的通用最优错配碱基规则。程序枚举三种替换、使用长度/GC/Tm/连续互补等筛选新位点、允许环引物，以及搜索范围和排序权重，都是软件的候选探索。默认四引物框架和第 3 位方案体现论文设计思路，不意味着完整复现实验。

分数用于比较有限搜索中的结构候选，不预测目标扩增、错配延伸、背景延迟、SNP 选择性、检测限或突变比例。Tm 按每个合成结合片段的完全匹配互补链计算，没有计算人工错配与实际模板间的双链 Tm，也不为整条拼接内引物给出单一结合 Tm。没有全基因组特异性检索或湿实验标定。新位点须通过已知两种等位模板及相应实验对照比较候选表现。
