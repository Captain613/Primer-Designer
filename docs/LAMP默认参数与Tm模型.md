# LAMP 默认参数的来源与 Tm 模型

核对日期：2026-10-09。以下是设计起点和数值参考条件，不是对每条序列都最优的实验条件。当前默认搜索范围由普通 LAMP、AS-LAMP、PA-LAMP 与 mLAMP 共用；参考普通 LAMP 的数值也不能证明这些 SNP 模式的等位选择性。

## 官方设计建议

Eiken 的 [PrimerExplorer V5 手册第一部分](https://primerexplorer.jp/e/v5_manual/pdf/PrimerExplorerV5_Manual_1.pdf)，正文第 1–2 页（该分卷 PDF 的第 7–8 页）给出：

| 参数 | 参考范围或条件 |
|---|---|
| F2 / B2 的 Tm | 59–61 °C |
| F3 / B3 的 Tm | 59–61 °C |
| F1c / B1c 的 Tm | 64–66 °C |
| LF / LB 的 Tm | 64–66 °C |
| 单个结合片段 GC | 40–65%；50–60% 可用于进一步优选 |
| F2 至 B2 的外缘跨度 | 120–160 nt，包含 F2、B2 本身 |
| F2 与 F1 的相应 5′ 端距离 | 40–60 nt；另一侧同理 |
| F3–F2 与 B2–B3 间隙 | 0–60 nt，不包含引物本身 |
| Tm 参考浓度 | 寡核苷酸 0.1 µM（100 nM）、Na⁺ 50 mM、Mg²⁺ 4 mM |

F1c/B1c 是内引物中的成环结合片段；F2/B2 才是完整 FIP/BIP 的 3′ 可延伸结合片段。不能把 FIP 或 BIP 两段拼接后的全长序列当作一个连续模板结合位点计算筛选 Tm。LF/LB 是可选环引物。

当前程序中“外侧模板跨度”对应 F3 至 B3，**不能将此字段的值直接改成上表 F2 至 B2 的 120–160 nt**；两者的端点不同。官方 [V5 操作说明](https://primerexplorer.jp/e/v5_manual/02.html) 的 Distances 定义区分了包含引物的跨度与不包含引物的间隙。

官方 [V3 参数表](https://primerexplorer.jp/v3_manual/04.html) 明列 Normal 的 F1c/B1c 长度 20–22 nt，F2/B2 与 F3/B3 为 18–20 nt；AT-rich 可延长至 25 nt 并降低 Tm 下限，GC-rich 可缩短至 15 nt 并提高 Tm 上限。这是**V3 分组参数表**，不可在未核对 V5 界面时将它改称 V5 当前默认。单一“片段长度”范围只能作为上述区段范围的共同搜索边界，不能声称完整复现这些分组设置。

[V5 手册第二部分](https://primerexplorer.jp/e/v5_manual/pdf/PrimerExplorerV5_Manual_2.pdf) 正文第 24 页建议：候选过少时逐步放宽，每次调整约 1 nt 或 1 °C；优选 F1c/B1c 比相应 F2/B2 高约 5 °C，同时注意同类正反向片段之间的 Tm 配平。宽松筛选不等于取消几何或结构风险要求。

## 当前默认搜索范围及调整依据

对用户提供的 Ren 等 mLAMP 补充材料 TP53 引物逐段核对后，发现 B3 为 17 nt，F2 在本程序参考浓度及完全匹配双链模型下的 Tm 约为 66.4/67.3 °C，分别超出原先 18 nt 最短和 65 °C 上限。这些 Tm 是程序对序列的计算值，论文未报告各区段 Tm、ΔG 数值或相应通用筛选阈值。仅把最短改成 17 nt、F2 上限改成 68 °C 可以解除这两个限制；当前按用户要求同时扩大长度、GC、各区段 Tm 和模板跨度，作为新位点的候选探索边界。

| 参数 | 调整前默认范围（v0.18 起） | 当前默认范围 | 官方常规推荐值 |
|---|---|---|---|
| 每个结合片段长度 | 18–27 nt | **17–30 nt** | 根据片段及模板 GC 分类，非统一范围 |
| GC | 35–70% | **30–75%** | 约 40–65% |
| F3 / B3 / F2 / B2 Tm，各自独立 | 55–65 °C | **52–68 °C** | 约 59–61 °C |
| F1c / B1c / LF / LB Tm，各自独立 | 60–70 °C | **58–72 °C** | 约 64–66 °C |
| F2 至 B2 外缘跨度 | 110–190 nt | **100–220 nt** | 120–160 nt |
| F3 至 B3 外缘跨度 | 120–300 nt | **110–350 nt** | 本程序额外筛选项 |

这些数值是共享 LAMP 设置中的工程搜索范围，不是 Ren 等论文给出的参数，也不改变 RPA 默认范围。mLAMP 仍默认固定 FIP、第 3 位人工错配及四条核心引物。PA-LAMP 的区域长度和 Tm 仍约束切后有效 DNA 区段。

本次调整保持几何要求：六区段互不重叠，F2 与 F1 及反向一侧的对应 5′ 端距离为 40–60 nt，外引物与相邻内区段的净间隙为 0–60 nt。默认排序继续偏好 GC 50%、片段长度 22 nt、F2–B2 跨度 140 nt 和 F3–B3 跨度 200 nt。新的默认 Tm 范围中点仍是前后两组 60/65 °C；用户修改某区段范围后，该区段的排序目标取有效范围中点，任意一端无限制时回退到 60/65 °C。

长度、GC、各区段参考 Tm、跨度及上述几何条件仍为硬筛选；GC 同时检查各区段及完整合成引物，连续同聚物超过 5 nt 的候选排除。AS-LAMP / mLAMP 先检查与输入模板匹配的原始 F2/B2，再检查人工改写后的两种等位片段。发卡、自互补、引物对互补及串联重复采用连续互补等启发式指标，只用于降分和提示，没有热力学 ΔG 阈值。F1c/B1c 比对应 F2/B2 至少高 1 °C 是排序偏好及提示条件，不是硬筛选。

报告记录实际筛选范围；用户手动设置的界限严格生效，不会自动放宽。扩大边界后仍采用有限候选搜索，范围内的每个布局不一定都会被保留；跨度超过官方常规范围的候选仍按实际值提示。

## 内引物预筛与候选保留

2026-10-09 调整候选裁剪，减少仅按单区段 GC、长度和 Tm 排序而过早丢弃完整 FIP/BIP 结构较优方案的情况。最终评分公式和筛选范围不因此改变；以下限额是软件计算策略，不是文献的引物设计要求。

| 搜索阶段 | 当前保留规则 |
|---|---|
| 每个起点的区域窗口 | F1c/B1c 各最多 4 个；F3/B3/F2/B2/LF/LB 各最多 2 个 |
| 固定 F2/B2 的内区段 | 从满足间距的局部排序前 12 个 F1c/B1c 中，先保留局部前 2 个，再按参考拼接内引物结构及 Tm 配平补充至最多 4 个 |
| 固定 F2/B2 的外区段 | 对应 F3/B3 各最多 2 个；与内区段组合后每侧最多 8 个布局 |
| 六区域布局分组 | 普通模式按 F2 起点的 20 nt 分箱；SNP 模式按方向及 F2/B2 长度分组，每组初筛最多 8 个布局；裁剪时先保留局部排序前 4 个，再按参考结构排序补足并去重 |
| 最终完整核验 | 最多 320 个六区域布局；裁剪时先保留局部排序前 160 个，再按参考结构排序补足并去重；普通模式最多 1,600 个分散 F2 起点；每条环引物核验最多 6 个窗口 |

内区段结构预筛使用按方向拼接的参考 FIP=`F1c+F2` 或 BIP=`B1c+B2`，评价完整序列的启发式自互补、3′ 自互补、发卡及串联重复，并考虑对应两个区段的 Tm 配平。保留局部前两名，使结构预筛补充候选，而不是完全替代局部指标。布局初筛也参考已计算的内引物结构风险，但分组与最终裁剪均预留一半局部优选名额，避免未经人工改写的参考结构独占保留名额。剩余名额由参考结构排序补足；两种排序有重叠时跳过重复，因此不是各截取固定一半后简单合并。最终仍按实际引物重新组成各独立反应，计算完整评分。

结构指标按实际序列共用缓存，减少重复计算。早期结构预筛仅核验不超过 256 nt 的拼接序列，每次设计使用 100,000,000 个估算计算单位的预算，单次成本估为 `4×序列长度²`。超过长度限额或预算时，早期排序回退到局部指标，并在报告中说明；这不是新增的引物长度硬限制，入围布局仍接受后续完整核验及其既有计算预算。

AS-LAMP/mLAMP 的预筛使用人工改写前的参考内引物，PA-LAMP 使用切后有效 DNA 内引物。SNP 等位替换、人工错配和 PA 阻断前体的实际序列在最终阶段完整核验，故早期结构排序不等同于最终得分。目录、前 12 个预池、每组 8 个以及最终 320 个限额仍可能遗漏高分方案；不能保证放宽范围后任意序列的最高输出分数都不下降，也不能声称找到全局最优引物。

## 本程序的数值模型

本程序保留 SantaLucia 1998 完全匹配 DNA 最近邻参数、双端起始项和自互补修正，采用其熵盐修正。依据 [PrimerExplorer V3 附录](https://primerexplorer.jp/e/v3_manual/03.html) 及 [V5 附录](https://primerexplorer.jp/e/v5_manual/03.html) 的 Mg²⁺ 等效换算，在参考计算中使用：

```text
Na_eff [M] = Na_raw [mM] / 1000 + 4 × sqrt(Mg_raw [mM] / 1000)
S_salt = S + 0.368 × (N − 1) × ln(Na_eff)
Tm [°C] = 1000 × H / (S_salt + 1.987 × ln(C / divisor)) − 273.15
```

其中 H 的单位是 kcal/mol，S 为 cal/(mol·K)，C 为 mol/L。非自互补序列 divisor = 4；自互补序列 divisor = 1，并在 S 中增加 −1.4 的对称性修正。

默认 50 mM Na⁺ 与 4 mM Mg²⁺ 对应约 **302.982 mM 等效单价盐**，并不表示真实反应中有 302.982 mM Na⁺。这是简化参考模型，不处理 dNTP 与 Mg²⁺ 结合、实际游离 Mg²⁺、甜菜碱、其他添加剂或 RNA/C3 修饰。

PrimerExplorer 附录写的是另一套公式：其 Tm 使用 SantaLucia 1996 引用和额外的 `16.6 × log10(Na_eff)` 温度项。本程序**没有再叠加这个温度项**，以免与 1998 熵盐修正重复计入盐影响。因此，本程序只是采用 PrimerExplorer 的设计建议及固定参考浓度，**不声称计算结果与 PrimerExplorer 相同，也不声称复制其算法**。引擎所用数值和报告应标明模型及参考浓度。

原始研究：[SantaLucia 1998, PNAS 95:1460–1465, Table 2](https://doi.org/10.1073/pnas.95.4.1460)。该模型为完全匹配双链的参考 Tm；人为错配引物所报 Tm 是其实际合成 DNA 对完全互补序列的估算，不是该引物与原始错配模板的实测熔解温度。

软件输入边界：Na⁺ 大于 0 且不超过 1,000 mM，Mg²⁺ 为 0–100 mM，寡核苷酸大于 0 且不超过 1,000,000 nM；等效单价盐超过 1 M 时明确拒绝计算，不静默截断或外推。上限属于模型实现的保护边界，不是建议使用的实验浓度。

## 版本兼容

旧三参数 `MeltingTemperature(sequence, Na_mM, oligo_nM)` 仍表示 Mg²⁺ = 0，其固定样例值保持不变。新设计应显式调用带 Mg²⁺ 的四参数重载；窗口前缀求和路径使用同一校正公式，避免界面、搜索和结果计算不一致。
